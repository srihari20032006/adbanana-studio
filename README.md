# AdBanana Studio — interactive concept website

A responsive, multi-section React + TypeScript concept site built with GSAP, Three.js and Lenis.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. For a production build run `npm run build`.

## What's included
- Immersive hero with a live Three.js object and responsive layout.
- GSAP reveal animations and Lenis smooth scrolling.
- Workflow, solutions, interactive AI Studio, insights, SWOT and Porter's Five Forces sections.
- Local image upload with drag-and-drop, visual direction and format controls.
- Simulated concept-generation state. The demo does not call AdBanana's production AI service and does not upload files.
- Editable ROI assumptions calculator.
- Responsive navigation and reduced-motion fallback.

## Accuracy and brand note
This is an independent concept/prototype, not an official AdBanana website. Product descriptions and strategic observations are illustrative and should be checked against current AdBanana product documentation before public use. Any performance, pricing or market metrics should be sourced and verified before publication. The AI Studio's "Generate" action is a front-end simulation, not a live AI generation API.
